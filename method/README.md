# Bundled method skills

Eight bundled skills travel with this kit: four close methods extracted from Anthropic's `finance` plugin and modified for FA Foundry (Apache-2.0), and four Foundry routing packs (`setup`, `close`, `bva`, `cash`) registered in `packs.json`.

They are not `authoring/SKILL.md` and they are not copied into `var/skills/`. That path stays hers.

See [FOUNDRY.md](FOUNDRY.md) for the runtime fence. See [NOTICE](NOTICE) and [LICENSE](LICENSE) for attribution. Connector placeholders: [CONNECTORS.md](CONNECTORS.md).

Shared professional guidance: [accounting basis and evidence](accounting-basis.md),
[close and account rollforwards](close-checklist.md), [model checks](model-checks.md),
and [variance/cash/forecast methods](forecast-models.md). All eight existing entry
IDs can read these fixed resources with `method-resource`; no arbitrary file path
is accepted. The skill and pack manifests return resource hashes and the
[support matrix](support-matrix.json), whose implementation/test/live/human states
remain separate. Guidance does not certify professional or statutory support.
