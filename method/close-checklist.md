# 月结、分录、对账与科目滚动

版本：finance-methods-20261023。先按 [accounting-basis.md](accounting-basis.md) 确认所需口径；
检查记录遵循 [model-checks.md](model-checks.md)。这里只复用已有控制、调整草稿、经理处置和月结状态。
Foundry does not post journal entries or initiate payments.

## F02 月结组织

触发：关闭指定期间、准备管理报表、核对未结事项。最低输入：期间、余额/明细、已授权来源、待办、上期未结项、截止政策。

按实际资料组织依赖：输入完整性 → 现金/往来对账 → 收入费用截止 → 科目附表 → 调整草稿 → 管理报表 → 差异解释 → 经理复核。
每项待办记录责任角色、截止日、依赖、来源、控制结果和具体未结原因。没有相关科目的任务不强加全部附表。

使用 finance_controls_save 和 finance_controls_run 的既有控制及当前任务的月结汇总状态。只有符合现有权限的已确认控制才计入；关键失败不能被完成率平均掉。经理接受差异应保留金额、原因和适用范围，不抹去原检查差异。草稿待复核、控制通过、月结归档和审计意见是不同状态。

资料或相关专业规则变化：生成后继版本并复算受影响的检查；旧归档可读，不能改写旧记录恢复绿色。未确认政策、缺失资料、尚未支持的计算分别列出受影响结论和下一步。输出经理复核底稿、关键差异、调整草稿及未结事项，不声称已完成外部账套关账。

## F03 分录、计提、预付与摊销

最低输入：经济事项、合同/验收/服务期间、原始单据、既有分录、映射、含税基础、冲回政策及后续发票处理。没有确认的资本化、抵扣或摊销政策时说明具体缺口。

1. 判断归属期间和剩余义务，再核对已有金额，避免把开票、收款与收入确认合并。
2. 用明确受益期间和方法形成分录草稿，关联来源与计算；可复用现有 adjustment 草稿，但不要创造过账能力。
3. 检查记账本位币借贷平衡，保留原币、汇率及汇兑差额。正常换汇不要求每个原币独立平衡；未知汇率不能猜，未支持折算只能声明未验证。
4. 逐笔选择完整计提结算路径。12 月服务 100、1 月账单及付款 100：

| 路径 | 12 月 | 1 月 | 核对 |
| --- | --- | --- | --- |
| 冲回后确认账单 | 借费用100/贷预提100 | 借预提100/贷费用100；借费用100/贷应付100；借应付100/贷现金100 | 1月净费用0，付款100，累计费用100 |
| 直接结算预提 | 借费用100/贷预提100 | 借预提100/贷应付100；借应付100/贷现金100 | 1月净费用0，付款100，累计费用100 |

不得混用两路径造成重复费用或负负抵消；发票金额与原估计不同时查明差额。预提义务不因跨月自动消失。
全年服务预收120且确认均匀履约、无税时，首月现金120、收入10、合同负债110；预收不能全算当月收入。
输出仅为候选分录、期间/冲回条件、计算、来源及复核事项。

## F04 总账、子账与银行对账

最低输入：双方范围/截止日、期初/期末控制总额、交易键、币种金额、状态和时间字段；匹配政策必须明确。

1. 先检查行数、唯一键、总额与重复/作废状态；保留双方原始定位。
2. 选双方支持的最低共同粒度。先按明确规则归组再连接，避免重复键多对多笛卡尔放大；没有业务标识不可按“金额刚好相等”自动配组。
3. 全外连接并分类：已匹配、金额差、单边、时点、映射、状态、待调查。禁止只内连接后称全部一致。
4. 重建两侧：已匹配金额＋未匹配金额＝各自原始总额；每一行必须有且只有一个归属，不通过任意净额抵消凑平。
5. 银行在途/未达支票若已正确记入 GL，通常是有证据的时间差，不能重复记账。子账有服务100而 GL 漏记，即使待审批也须检查截止和计提；不是统一等1–5天即可。期后清算支持判断，但不自动改变期末确认。
6. 每个差异记金额、账龄、原因假设、来源、下一动作、责任角色和实际预期清算日期。陈旧项和反复出现项优先调查。

数字容差、显示舍入和管理重要性分开。缺少一侧资料时输出覆盖限制与所需明细；匹配规则未确认时保留未配对项。输出差异底稿和候选调整，调整仍是草稿。

## F05 科目滚动

最低输入：同口径期初/期末、全部新增/减少、核销、汇兑、重分类和批准调整。使用现有 signed_sum 算术控制及明确符号，不能将一个全科目正负号模板套到所有余额。

| 附表 | 调节与防错 |
| --- | --- |
| 应收毛额 | 期初＋新增账单−回款−贷项−核销±有据调整＝期末；收入不必等于开票 |
| 应收准备 | 期初＋减值费用−核销使用±有据调整＝期末；净额＝毛额−准备，不再重复扣核销 |
| 合同负债 | 期初＋履约前已收款−已确认收入±有据变化＝期末 |
| 预提/预付 | 期初＋新增−结算/摊销±调整＝期末；与费用确认和现金分开 |
| 固定资产 | 成本和累计折旧各自滚动，再核对净值；现金capex不等于当期折旧 |
| 债务 | 期初＋借入−本金偿还±有据变化＝期末；利息单列 |
| 留存收益 | 期初＋净利润−股利±批准调整＝期末；OCI单列 |

示例应收毛额100＋80−50−10−5＝115；准备10＋4−5＝9；净额106。未结争议20继续包含在毛额115中单列，不能删除；分析非争议子集95时明确调节回115。
未知变化保持为可见差异，不插入无来源“其他”调节数。输出每项发生额、来源和余额差额。科目余额滚动与复制工作簿换月是不同能力。

## F07 应收、账龄与收缴

最低输入：期末未结发票、到期/开票日、付款核销分配、状态、期初欠款、明确的收缴分子分母、适用政策。
先确认账龄基准及已结/作废处理，未分配回款和贷项单列；有依据后再分配。争议状态不能自动变成已结、核销或从总体删除。

重算当前与综合收缴率并保留定义：当期100收90、期初欠100清10，分别90%和50%；可能更高、更低或相等。零分母是不可得；若任务只要求子集，列排除金额并重建总体。
DSO需声明应收/合同资产范围和收入期间。账龄只是风险信号；减值只能使用明确批准的政策/损失矩阵及前瞻判断，算术闭合不能证明完整准则合规。
输出可追溯余额/准备/净额、账龄、收缴率、集中度、重点核查对象和政策缺口。资金压力交给 F08，不能由收缴阈值单独判断现金安全。
