# 次要入口与折叠层级验收（0.2.4）

“会话信息”改为“对话工具”，展开后说明可查看当前对话与分析方式、导出排查日志。“Session log”改为“导出排查日志”。说明是真实 DOM 文本，保留原生对话层级、分析方式及日志下载回调，适配仍受固定来源哈希约束。
