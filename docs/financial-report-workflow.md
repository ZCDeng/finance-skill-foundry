# 经营分析文稿工作流

在任务的“文稿”页中选择版本。阅读跟随应用主题，编辑保留连续正文，打印预览使用白底 A4。报告信息填写公司、期间、币种与单位；目录按已有章节生成。新文稿可使用经营分析章节模板，空章节不自动生成结论。

## 编辑和版本

可视化编辑支持标题、段落、列表、链接、PNG/JPEG 图片、表格合并拆分、章节末附注、分页及撤销重做。修改后保存为新版，旧版、运行引用和事实记录保留。导出或交给助手前会保存当前改动。改动内容会重新进入未阅状态，执行成功不等于财务结论已获认可。

Markdown 源码适合轻量文本修改。合并表格、图片及分页可能无法完整表达；先查看降级预览，保留完整结构版本以便恢复。

## 正文组织

每段只讲一个主题。先用短段给出结论和重要影响，再以比较表或条列说明数据；完整计算式单独成段，来源和详细口径放到对应章节末附注。比较基准、适用条件和未确认事项应紧随相关判断，避免读者把情景测算当作已实现结果。

例如，预算和滚动预测的多个指标使用“项目／年初预算／滚动预测”表；归母净利计算另起一段；表格后的附注记录原工作表及单元格。数值占位符仍放在数值位置，附注编号不能替代计算事实绑定。

旧文稿可使用“整理段落”查看分段预览。采用后才修改编辑内容，可以撤销、重做，并按现有流程保存为新版。自动整理只在长段的完整句、分号和已有换行处分段，保留文字、数字和引用顺序；表格、代码、附注以及无法安全划分的内容保持原样。复杂长句的业务主题仍需在编辑器内整理。

“重检当前正文”会单独给出正文阅读建议。它不会更改数字核对、问题覆盖、来源追溯或经理审阅结果。

## 文稿图表

文稿可插入比较条形图（含分组）、趋势折线图和解释流程图，随文稿版本保存并继续编辑。数量图选择当前任务已有的成功计算及归档图，再选择类别、数值列、图题、结论和单位；原值、运行与来源快照由服务保存。改图不会重跑计算，修改数据或假设需先生成新的计算结果。

条形图的类别数×系列数最多为 12（缺失位置也计入），折线最多 24 个时间点，均为 1–3 个数值系列，每稿最多 20 张图。图内文字过密时，按提示缩短文字或拆分图表。类别必须非空且唯一，折线按结果中的顺序呈现时间；不自动排序、截取前几行或补零。负值、零和缺失分别展示，数据表保留精确原值。单位是展示声明，不执行换算；比较前需确认币种、单位、期间及口径一致。数据过密或需要逐项查数时使用表格。

流程图包含 2–6 步及相邻步骤的关系，用于说明处理流程或作者分析。来源默认“作者分析”，不据箭头认定因果，也不视为计算证据。每张图的图题、结论、单位或来源与正文一起阅读；没有依据的业务原因仍需明确为假设。

方法适配自 [diagram-design](https://github.com/cathrynlavery/diagram-design) 的关系选型与 SVG 布局，以及 [huashu-report](https://github.com/alchaincyf/huashu-report) 的直接标注、图表/结论/来源组织和数据展示检查。具体支持范围、固定来源版本与模型调用示例见 [随包文稿图表方法](../method/report-visuals.md)，许可见 [NOTICE](../method/NOTICE)。

## 五种格式

| 格式 | 导入 | 导出 |
| --- | --- | --- |
| Word | 标题、正文、表格、图片和附注转为可编辑结构；复杂样式、页眉页脚及分页位置需核对 | 可编辑 DOCX，A4、规范标题、目录字段、重复表头及页眉页码 |
| PDF | 原页与提取草稿对照；复杂表格、扫描页可重试本机 OCR Studio | 正式预览生成可选择文字的 PDF |
| HTML | 支持的正文结构及同目录 PNG/JPEG；清除脚本和外部行为 | 内嵌字体、图片、目录和样式的离线文件 |
| Markdown | 正文、标题、列表、表格、链接及同目录 PNG/JPEG | 确定性正文，数字保持原精度；图片可内嵌，结构损失有提示 |
| Excel | 选择工作表和 A1 区域，保留来源定位；公式取缓存值，缺失会提示 | 概览、分段正文、财务表、附注与依据工作表 |
| PPT | 按幻灯片顺序导入每页的文字和表格（含合并单元格），每页一个「第 N 页」标题并记录页码；图表、图片、版式、隐藏页和备注不导入，数字需复核 | 不支持，文稿不能导出为 PPTX |

导入先生成预览，采用后再保存正式文稿。导入文件中的审核状态和证据声明不会自动成为应用认可的事实。转换有阶段提示，可取消；已经开始写入正式记录时会完成该次保存，避免取消后留下半条记录。

结构图表在 HTML/PDF 中使用 SVG，在 Word 中转为等比图片并保留图注。Excel 数量图附原生图表和精确数据表，流程图以步骤和关系工作表保留；Markdown 使用数据表或流程文字。外部文件重新导入不保证恢复原生可编辑图表，需保留应用内的结构文稿版本。

## 本地文件和识别

原始文件保存为任务内快照并校验哈希。导入 HTML/Markdown 时，仅嵌入所选文件同目录及子目录中的 PNG/JPEG，单张最多 2 MiB，总计最多 16 MiB。外部图片、父目录资源和不支持格式不会自动加载；缺图会给出转换提示。单个导入文件上限为 32 MiB。

PDF 识别使用本机 OCR Studio，应用不捆绑模型。服务未启动或识别失败时保留原页与已提取文字；启动 OCR Studio 的识别服务后，可从导入预览重试。扫描识别结果需要核对金额、单位、页序和表格列。

Word 目录是可更新字段，在 Word 中更新目录即可显示当前页码。不同排版引擎不保证完全相同的分页，因此附注采用章节末编号形式。宽表导出按列分段并重复项目列；合并表格的打印分段会重复跨段标签，编辑版本仍保留合并结构。

## 外部报告数字复核

导入预览里的「复核数字」和已保存导入文稿下的「复核外部报告数字」，把文稿里的每个数字（含单位、位置和前后原文）与当前任务的套表单元格、资料表金额列和计算结果逐项比对，结果分为一致、四舍五入后一致、疑似单位换算、不一致和需人工核对。只用当前有效、本会话可见的资料，被新版本取代的快照不参与；OCR 识别的无页码文字一律列为需人工核对。比对按数值和行名、指标名进行，不理解语义。复核结果另存为一条不可修改的记录，不改动文稿或其复核状态；复核只比对数字，不判断表述是否恰当，也不代表报告可以对外发送。

本轮不包含 PPTX 导出、实时多人协作、Excel 公式重算和完整法定年报编制。
