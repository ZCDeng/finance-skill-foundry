# 正文可读性修复

用户要求：结论、引用和计算公式需要清晰的段落与分行，避免长段堆砌。沿用现有 ReportDocument、编辑器、版本记录和五格式转换，不新增依赖。

## 实施顺序

1. 先覆盖已有长中文段落、精确数字、事实占位符、引用、富文本与附录的回归行为。
2. 在实际供助手读取的文稿生成指令中规定：每段一个主题，先给有证据的结论；同维度数字用比较表或条列；完整计算式单独成段；来源用章节末附注；条件和未确认事项紧随相关结论。不补造原因、行动或结论。
3. 为旧稿提供“整理段落”预览：只在确定的句界、分号或已有换行处分段；保持所有文字、标点、数字、顺序、格式与来源定位。跳过表格、代码、附注和不确定的复杂内容。用户采用后才更新编辑内容，可撤销并保存为新版。
4. 修复正文/编辑区段落留白的实际 CSS 覆盖；让完整公式和附注能独立阅读，保持五格式中的真实段落结构。
5. 将现有物业报告整理为新的可审阅版本，核对金额、比较基准、公式、原文引用和源文件哈希。对新旧内容做逐项映射，保留原版。
6. 完成针对性测试、类型检查、构建、真实阅读和导出验证；提交推送并更新安装版，保留验收证据后清理替换包。

## 边界与验收

段落整理是确定性的结构编辑，不推断业务语义、不自动把括号内容改成可信证据、不更改审核结论。语义重组通过明确写作规范和可审阅的新版本完成。数值、币种、期间、负号、公式、事实占位符、来源引用和原始文件保持完整。

验收包括：预览不保存、取消不改变原稿、采用/撤销/重做、版本保留、长句保护、重复执行稳定、合并表格及图片不受影响，DOCX/HTML/Markdown/PDF/XLSX 使用相同的保存段落。
