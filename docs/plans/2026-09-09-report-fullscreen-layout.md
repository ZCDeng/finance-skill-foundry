# 全屏文稿布局修复

问题：阅读和编辑正文固定为 42em 且靠左，父级工具栏铺满窗口，形成明显不对称的右侧空白。目录断点依赖窗口宽度，在大窗口的窄分栏中仍可能挤压正文。

修复顺序：保留现有正文和编辑行为；将目录、正文、工具栏作为同一个有最大宽度的居中布局，正文适度放宽至约 56rem；缩短工具栏与标题之间叠加的留白；按文稿容器宽度切换目录布局。打印页面仍使用原 A4 预览。

验证：用实际 Electron 渲染测量宽窗口、全屏、窄结果分栏的正文／工具栏对齐、整体居中与横向溢出，检查阅读、编辑和打印预览截图；运行前端测试和类型／构建检查；更新安装包并从安装版复验，提交推送后清理替换包。
