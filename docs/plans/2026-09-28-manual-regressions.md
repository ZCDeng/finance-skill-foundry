# 0.3.3 手工验收问题修复

用户在安装版报告：深色模式下，待确认工作簿的表头选中行出现浅底白字；任务缺少可用的归档和删除流程。

## 修复范围

1. 表结构预览、资料检查和科目映射共用的三处表头样式改用已有主题底色及文字色，避免不存在的变量触发浅色回退。
2. 任务增加在用、已归档、回收站状态。归档和移入回收站保存到任务元数据，保留文件与历史，提供恢复入口。旧任务没有状态字段时按在用处理。
3. 归档或移入回收站后切到对应分类，显示任务状态与恢复入口；恢复后返回进行中，保留文稿选择。后台默认当前任务切换至下一项在用任务或清空。成果库保留归档成果，回收站成果暂时隐藏；归档文稿恢复任务后继续打开和编辑。
4. 不增加依赖，不处理用户真实任务数据，不提供永久清空。

## 验收方式

- 单元及集成验证：CLI 状态持久化、旧任务兼容、当前任务切换、成果可见性、恢复和失败处理。
- 桌面专项：用隔离 profile 和合成多工作表预算文件重现原问题；浅深主题、1280/1080 两种宽度测量表头实际文字对比度，并保存截图。通过真实 UI 验证归档、回收站、恢复与重启。
- 发布：重新冻结后端、构建并签名 0.3.4，Apple 公证通过后替换安装版；验证安装内容、签名及公证票据与发布归档一致，再发布版本和校验值。

本文件记录执行范围与验收方法，实际结果另列入 0.3.4 发布验收记录。
