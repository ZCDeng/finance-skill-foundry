# FA Foundry 0.3.4 发布验收

目标平台：macOS Apple Silicon（arm64）。本版修复 0.3.3 手工验收发现的表头对比度及任务归档、删除问题。应用实现提交：`ea0a7d8e3ca1840e07d405ad7b83545cf1e6a289`（包含前一实现提交 `1fb63f7`）。

## 行为与范围

- 表结构预览、资料检查与科目映射的表头复用现有主题底色和文字色，去掉未定义变量导致的浅色回退。
- 右上角任务工具可归档任务或移入回收站；侧栏支持进行中、已归档、回收站分类，停用任务页可直接恢复。
- 归档与回收只修改元数据，保留源文件、历史会话和保存的方法。成果库保留归档成果、隐藏回收站成果，恢复后重新显示。
- 停用任务不再挂载分析编辑界面，新的桌面对话入口要求恢复；归档文稿保留选择，恢复后继续打开。
- 修复慢归档响应覆盖后续分类、分类加载时重复点击造成旧列表滞留，操作失败没有提示，以及回收后成果库短暂显示旧缓存、旧响应覆盖新列表的问题。
- 未增加依赖；任务回收不进行物理删除。后端生命周期管理改变列表和默认当前任务的可见性，不构成所有显式 CLI 命令的全局只读权限。

## 修改文件

- `app/src/views/analysis.css`：复用现有主题色，去掉无效表头底色回退。
- `foundry/task.py`、`foundry/cli.py`、`foundry/analysis.py`：生命周期元数据、CLI 操作与历史方法发现。
- `app/electron/{reads,writes,preload}.ts`、`app/electron/ipc/{contract,register}.ts`、`app/src/bridge.ts`：任务状态与操作跨进程传递。
- `app/src/App.tsx`、`app/src/components/Workspace.tsx`、`workspace.css`：分类、任务操作、失败提示及列表竞态修复。
- 对应 Python/前端测试、`tools/verify_ui_manual_regressions.cjs` 与合成 XLSX fixture；`app/package*.json` 更新至 0.3.4。
