# 文稿工具栏整理

用户截图中的文稿标题、状态、外层编辑按钮和内层模式切换来自两套布局，形成两排互不对齐的操作。目录也重复显示“目录”和“章节目录”。

先运行现有阅读／编辑、保存、导出和继续分析回归测试。随后删除外层重复的阅读／编辑按钮，将文稿名称、状态和继续分析入口组合进 ReportEditor 的同一工具栏。工具栏跨目录与正文两列，左侧呈现名称和状态，右侧排列模式及操作；正文与目录共享原有列宽。窄面板使用明确的纵向排列。目录保留一个可折叠标题。

保持正文、未保存编辑、版本、导出及助手交接逻辑；不新增依赖。用实际 Electron 验证全屏、宽窄分栏、阅读／编辑／打印、目录折叠、导入／导出入口及助手交接。通过前端回归、类型检查、打包和安装版复验后，提交推送并清理替换包。
