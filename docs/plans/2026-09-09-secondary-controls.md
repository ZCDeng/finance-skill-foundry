# 次要入口的用途与视觉层级

本轮处理三个问题：对话“会话信息”缺乏用途说明；文稿页折叠入口与普通说明文字难以区分；文稿版本选择占满一整行，视觉强调超过实际使用频率。

先运行原生客户端适配、版本切换、未保存恢复和文稿编辑回归。对话侧保留原生功能及权限语义，将入口改为可理解的用途名称，并补充简短说明。文稿版本沿用既有搜索和选择行为，将当前版本入口缩成次要控件，完整标题、状态、时间和编号在展开后查看。折叠入口使用适度的主题适配色，保留方向箭头、悬停和键盘反馈，避免仅靠颜色区分。

不新增依赖，复用现有选择器和原生 details。验证单版与多版切换、搜索、切换后恢复未保存编辑、鼠标与键盘展开、深浅主题、全屏与窄分栏。候选包与安装版均进行实际交互检查，再提交推送并清理旧包。
