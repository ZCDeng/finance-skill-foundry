# FA Foundry 0.15.0-beta.1 阶段预发布

日期：2026-10-27。定位：财务方法、确定性计算、来源绑定和交付校验的工程阶段版本；完整财务验收尚未完成。稳定下载仍为 0.14.4。

## 本阶段交付

- 扩充内置财务方法资源：会计口径、月结、模型检查、预测与三表边界，以及能力支持矩阵。
- 增加专业规则、确认依据、交易检查与专业审批链路；解释、计算事实、来源、需求登记、保存回执和最终回复建立关联校验。
- 修复收缴率、清欠与旧应收措辞，金额与计数身份、账龄标识、同月期间和情景路由等已验证的问题；保留无法确定口径时的诊断。
- 增加量价计算适配、调整金额类型检查、公式复制模式检查，以及只读方法预设的首次与重复安装修复。
- 将冻结开发算例、回归测试和评测工具纳入版本。开发算例可见，不代表独立未见集；历史运行失败不会被新版或补充算例覆盖。

## 明确未修复和未验收的范围

1. **E01 内容哈希契约**：当前草稿哈希含 11 个字段，冻结校验器要求原 10 个字段。最小修复已在隔离副本完成有界测试与独立审查，尚未集成本版本。旧稿和旧失败原样保留。
2. **E02 范围与终态**：同时保留 `price_quantity` 和 `public_facts` 的合法原生量价来源，会触发通用比较范围拒绝。另有来源绑定、方法资源读取顺序、数字引用、数量单位与未终态模型等待问题；不得用删除来源、补零或放宽时间限制代替修复。
3. **M02/M06 与其他专业控制**：七字段历史审批与十一字段当前专业要求尚未完成兼容闭环。显式十一字段的补充验证不能改变原测试失败。
4. **剩余高风险场景**：M09、跨期与确认口径、三表业务语义、完整性/截断和目标约束仍需按后续方案逐项验收。局部数值正确不等于业务条件完整。
5. **完整验收**：新最终候选上的完整 283 槽位、独立语义复核、两名人工财务审查者及分歧裁决、独立未见集尚未形成完整通过证据。
